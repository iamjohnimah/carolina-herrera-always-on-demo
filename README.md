# Carolina Herrera · SPREEAI Always On demo

Public, standalone six-garment partner demo. This repository contains the built storefront used by GitHub Pages.

Original Carolina Herrera product photography, garment videos, French RTW details and compact integrated SPREEAI controls. Includes redesigned try-on, Twin/profile selection, comparison, outfit building, favorites and simulated sizing.

This is an independent demonstration, not the official Carolina Herrera store. No checkout or payments. Products and media belong to their brand. Fit visualizations are labeled illustrative mockups, not calibrated sizing predictions. Live AI previews connect to SPREEAI staging and depend on service reachability. No credentials, personal photos or user sessions are included.

Serve this folder with any static web server. The hash-based routes work directly on GitHub Pages.
